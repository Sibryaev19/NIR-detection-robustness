# NIR: Исследование алгоритмов распознавания объектов в сложных условиях съёмки

НИР магистранта 6132-010402D Сибряева Е.В. (Самарский университет, каф. технической кибернетики).
2 семестр (сдан): оценка устойчивости RT-DETR к синтетическим искажениям аэровидеопотока.
3 семестр (текущий): развитие исследования — в планах сравнение детекторов нового поколения
и/или методы повышения устойчивости (см. `.for_agent/`).

## Суть эксперимента 2 семестра
Детектор **RT-DETR-L** оценивается на 101 размеченном кадре аэросъёмки (4 видео, классы
car/truck/bus) при 5 типах искажений × 10 уровней + clean = 51 серия.
Метрики: AP@50, Recall, F1, Mean IoU, робастность mPC/rPC.
Ключевые результаты: размытие — критичный фактор (AP@50 0.67→0.05); яркость почти безвредна;
**AP@50_clean = 0.6704, mPC = 0.5474, rPC = 0.8166**.

## Структура репозитория
```
docs/                  — отчёт за 2 семестр (docx + извлечённый текст)
new_program/           — рабочий пайплайн:
  config.yaml          — ВСЕ параметры (датасеты, искажения, уровни, метрики)
  make_annotation.py   — полуавтоматическая разметка (модель + ручная правка, OpenCV GUI)
  run_experiments.py   — инференс по всем сериям искажений → predictions.json
  make_results.py      — расчёт метрик → CSV + графики
  fast.py              — сборка графиков в сетки 2×2 для отчёта
  datasets/<name>/     — ground_truth.json (эталонная разметка; кадры не в git)
  experiments/exp_merged_4videos/ — эталонная разметка эксперимента + metrics/*.csv
tools/
  extract_frames.py    — нарезка видео на кадры с превью (нужна при расширении датасета)
.for_agent/            — память агента: контекст проекта, планы
```

## Тяжёлое (не в git)
Веса моделей, видео, кадры датасетов, predictions.json передаются отдельно (флэшка)
и раскладываются по путям из `flash/README` (копия — у владельца репо). После раскладки:
```
new_program/rtdetr-l.pt
new_program/datasets/video*_v1/frames/
```

## Воспроизведение эксперимента
```bash
pip install -r requirements.txt
cd new_program
python run_experiments.py   # инференс всех серий (прогресс сохраняется, можно прерывать)
python make_results.py      # метрики → experiments/<name>/metrics/
python fast.py              # графики 2×2
```
