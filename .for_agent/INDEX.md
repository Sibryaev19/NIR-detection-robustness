## Активная задача
- **Задача:** выбрать направление исследования 3 сем. НИР (для отчёта + студенческой конференции)
  через изучение области и пробные эксперименты. Пользователь: «не спешить, изучать,
  экспериментировать». Дедлайн отчёта не приоритет (пользователь готов вкладываться сверх него).
- **Текущий шаг:** 1 — Понимание/изучение области

## Первые шаги на компе (Ubuntu) — чек-лист переезда
1. На ноутбуке: создать приватный GitHub-репо (напр. `nir-object-robustness`) → `git remote add origin …` → `git push -u origin main`.
2. На Ubuntu: `git clone` → раскладка тяжёлого с флэшки по `flash/README.txt`.
3. Окружение: venv + `requirements.txt`, torch ставить с индексом cu128 (Blackwell! см. context.md).
4. Проверка: инференс RT-DETR на GPU (`device=0`) на паре кадров — убедиться, что окружение живое.
5. Воспроизвести эксперимент 2 сем. на GPU (сверить AP@50_clean ≈ 0.6704) — база для будущих сравнений.
6. Дальше — изучение области (карта области → пробные эксперименты → выбор направления A–D).
